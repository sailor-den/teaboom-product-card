# Карточка товара Teaboom.ru

Верхняя часть карточки товара **Ананасовый улун** для интернет-магазина [Teaboom.ru](https://teaboom.ru/product/ananasovij-ulun).

Страница собрана на HTML5, SCSS и ванильном JavaScript

- репозиторий: https://github.com/sailor-den/teaboom-product-card
- демо: https://sailor-den.github.io/teaboom-product-card/

## Что сделано

- изображение, название, категория, артикул, цены и короткое описание;
- переключение фасовок 100 / 500 / 1000 / 5000 г: меняются цена, старая цена, артикул и выбранное состояние;
- кнопка «В корзину» с отдельным hover-состоянием (реальная корзина не подключена);
- адаптив под desktop 1440 px, tablet 768 px и mobile 375 px;
- стилистика Teaboom: слоновая кость, акцент `#f5d730`, шрифты Open Sans и Oswald.

## Запуск

Скомпилированный CSS уже лежит в репозитории. Достаточно открыть страницу:

1. Скачайте проект или клонируйте репозиторий.
2. Откройте `index.html` в браузере.

Либо поднимите локальный сервер из корня проекта:

```bash
npx --yes serve .
```

## Стили

Если нужно править SCSS:

```bash
npm install
npm run watch:css
```

Однократная сборка:

```bash
npm run build:css
```

## Структура

```
index.html          — разметка карточки
css/main.css        — собранные стили
scss/               — исходники SCSS
js/product.js       — переключение фасовки и кнопка «В корзину»
assets/images/      — логотип и фото товара
```
